# 黒い海の交易者

新石器時代の黒海沿岸で、舟に乗り、村から村へ品物と知識を運ぶ交易ゲーム。終わりはなく、好きなだけ旅を続けられる。
地図は実際の地形に近い黒海全体・アゾフ海・マルマラ海・エーゲ海北部で、ドナウ・ドニエプルなどの川をさかのぼれる。旅は西岸（ヴァルナあたり）の数港から始まる。

`index.html` をブラウザで開けば遊べる（サーバー不要）。進み具合はブラウザに自動保存される。

いまはシステムのテストプレイ用に、大丸木舟と双胴舟・仲間6人・多めの積荷と金貨で始まる（`data.js` の `start`）。本来の始まりは `normalStart` に残してある。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `js/data.js` | 地理（緯度経度）・時代・町の大きさ・品物・知識・船室・船・人物・村・航路・水族・好感度の段階・ルールの数値。中身を足すときはまずここ |
| `js/geo.js` | 緯度経度から地図（海・島・海峡と川・地名）を組み立て、村・航路・海域の位置を地図の点に直す |
| `js/stories.js` | 人物ごとの会話と、好感度のイベントの文章 |
| `js/core.js` | ゲーム状態、季節の進行、保存 |
| `js/economy.js` | 物々交換・金貨での売り買いと価値の計算、保存食で差額を合わせる、村が扱う品物、村の在庫の回復 |
| `js/civ.js` | 村の時代（知識で決まる）・人口と町の大きさ・景気・研究者・知識を編み出す |
| `js/bonds.js` | 好感度（話す・おごる・贈る・デート）、恋人と結婚、イベントの発生、酒場の娘を誘う、酒場の噂 |
| `js/family.js` | 子供ができる・生まれる・育つ・仲間になる |
| `js/knowledge.js` | 知識を学ぶ・教える |
| `js/fleet.js` | 船団、船室の席と効果、人手と水夫、乗り換え、造船の依頼、仲間の勧誘 |
| `js/travel.js` | 既知の航路での自動航行・食料 |
| `js/sea.js` | 外海の航行（毎フレーム進む）、霧、新しい港の発見、追ってくる水族 |
| `js/combat.js` | 水族との戦い（一人ひとりが打ち合うシミュレーション）・逃走 |
| `js/portrait.js` | 人物の似顔絵（胸から上のアニメ風 SVG。`look.img` に画像を書けばその絵を使う） |
| `js/seaview.js` | 航海画面（canvas）。操作と描画だけ |
| `js/battleview.js` | 水上戦の画面（canvas）。描画だけ |
| `js/scene.js` | 酒場と仲間の場面。一枚絵の中で人を選び、コマンド（話す・おごる・贈る・デート・結婚・誘う・水夫を雇う）を選ぶ |
| `js/ui.js` | 画面の切り替え、右の枠、操作 |

## 足し方

- **品物・村・知識**：`data.js` に1項目足すだけで、交換画面・地図・知識画面に出る。品物の `era` は村が扱いはじめる時代、`cat` は交換画面の絞り込み（`goodCats`）、`lux: true` は大きな町ほど欲しがる飾り物。村の `goods` は `{ 品物: [普段の在庫, 大事にする倍率] }`。
- **時代**：`eras`。村の時代は、知っている知識の `opensEra` の一番大きいもの。品物・船の `era` でその時代から使う・造る物を決める。`rules.coinEra` 以上の村は金貨で売り買いする（それより前は物々交換で、差額は保存食で合わせられる）。
- **人口と町の大きさ**：`sizes`。村の `pop`（はじめの人口）と `land`（知識なしで養える人数）。養える人数は知識（`cap`、書かなければ `rules.capPerKnowledge`）と研究者で増える。船の `size`・`recruits` の `size` で、その大きさになると造れる船・現れる人を決める。どの村も知らない知識は `invent: { town, size }` を付けると、研究者のいるその村がその大きさに育ったとき編み出す。
- **地図**：`geo` に緯度経度で書く。`seas` は海の輪郭、`islands` は島、`waterways` は海峡と川（川は河口から上流の順に点を並べると、さかのぼるのが遅く下るのが速くなる。速さは `rules.upstream`・`downstream`）。村の `at`、航路の `via`、水族の海域の `at` も緯度経度。航路の季節数は道のりと川の流れから自動で決まる。運河は `waterways` に一本足せば舟が通れる。
- **好感度・酒場**：好感度の節目とほうびは `bondStages`（`lover: true` の段階で恋人になる。恋人の段階は女性だけ）。村の `tavern` に酒場の名前と娘（`people` の id）を書く。人物のせりふとイベント（`talk`・`events`・`date`・`wedding`・`birth`・`grown`）は `stories.js` に人物の id で足す（書かなければ汎用の文章になる）。イベントは18歳以上の人物だけに起きる。
- **恋人・結婚・子供**：数値は `rules` の `dateLove`・`marryAt`・`weddingGifts`・`childChance`・`pregnancySeasons`・`childGrowth`・`childJoinAge`。子供の名前は `childNames`。子供は家族として扱い、好感度や恋のイベントは起きない。
- **水夫**：船の `crew` が動かすのに要る人数。仲間と水夫の合計が足りないと船足が落ちる。雇う値段や戦いでの強さは `rules` の `sailor…`。
- **船室**：`cabins` に種類を足し、効果を `fleet.js` の `Fleet.bonus` に書く。船の `cabins` に並べればその船に付く。
- **船**：`ships` に足し（`cabins` の先頭は必ず `captain`）、造れる村の `shipyard` に名前を入れる。`requires` で造る村に必要な知識を指定できる。
- **人物**：`people` に足す（性別・年齢・強さ・船室ごとの適性・好きな物・見た目）。村の `recruits` に id を書けばその村で仲間にできる。似顔絵を絵にしたいときは、画像を `img/` に置いて `look.img` にパスを書く。
- **水族**：`raiders` に相手を、`encounterZones` に出る海域を足す。
- **隠れた港**：村に `hidden: true` を付けると、外海で近づくまで地図に出ない。その村につながる `routes` は、両端を見つけた時点で自動航行に使えるようになる。
- **陸路**：`modes` に種類（例 `land`）を、`routes` に `mode: 'land'` の道を足し、`Fleet.mode` が陸の旅のとき `land` を返すようにする。
- **子供の成長・集落づくりなど季節ごとの仕組み**：新しいファイルで `Game.onSeason.push(state => { ... })` を登録し、`index.html` に読み込む。仲間は `state.party` の配列（`people` の写しで `age` を持つ）なので、季節ごとに年を取らせたり、成長した子を加えたりすれば、船室への配置・戦い・食料の計算にそのまま反映される。
- 保存形式を変えたら `data.js` の `version` を上げる（古い保存は読み込まれず、新しく始まる）。
